## ご利用前に

- 本Petは Codex 向けの**非公式カスタムPet**です。OpenAIによる公式配布物ではありません。
- wonderくんは Wonder Tech Hub のキャラクターです。利用条件は [TERMS.md](TERMS.md) をご確認ください。

## インストール方法

1. このフォルダ内の `wonder-codex-pet-v2.zip` をダウンロードします。
2. ZIPファイルを展開します。展開後に `wonder` フォルダがあることを確認します。
3. `wonder` フォルダを、お使いのOSに応じて次の場所へコピーします。

   **Windows**

   ```text
   C:\Users\＜Windowsのユーザー名＞\.codex\pets\wonder
   ```

   **macOS / Linux**

   ```text
   ~/.codex/pets/wonder/
   ```

4. Codex を再起動します。
5. Pet の設定から **wonderくん** を選択します。
