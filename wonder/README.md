# wonderくん

Wonder Tech Hub の AI学習サポーター、wonderくんの Codex Pet です。

公式X: [@WonderTechHub](https://x.com/WonderTechHub)

## インストール方法（Windows）

1. このフォルダ内の `wonder-codex-pet-v2.zip` をダウンロードします。
2. ZIPファイルを展開します。展開後に `wonder` フォルダがあることを確認します。
3. `wonder` フォルダを、次の場所へコピーします。

   ```text
   C:\Users\＜Windowsのユーザー名＞\.codex\pets\wonder
   ```

4. Codex を再起動します。
5. Pet の設定から **wonderくん** を選択します。

## 同梱内容

- `pet.json` — Petの設定ファイル
- `spritesheet.png` — v2アニメーション画像
- `wonder-codex-pet-v2.zip` — 配布用パッケージ
- `contact-sheet.png` — 動作一覧
- `look-directions.png` — 16方向の視線確認画像
